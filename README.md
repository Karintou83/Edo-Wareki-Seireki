# 和暦→西暦 (wareki→seireki)

日本語版Wikipediaなどの記事を書くときに、和暦(元号)の**年**に、西暦の**年**を併記する VS Code 拡張機能です。
応仁(1467年)〜令和に対応し、江戸時代の記事を書くことを想定しています。**月日は扱いません**
(旧暦の月日は出典による差があり、どの暦の日付かを確定できない場合があるため)。

`天正18年` と書くと、`[[天正]]18年（[[1590年]]）` になります。

## インストール
1. [Releases](../../releases) から、最新の `wareki-seireki-x.y.z.vsix` をダウンロードします。
2. VS Code の拡張機能の画面(`Ctrl + Shift + X`)を開き、右上の「…」→「VSIX からのインストール…」で、そのファイルを選びます。
3. VS Code を再読み込みします。

## 注意
- 年のみの対応です。月日、旧暦と新暦の差は扱いません(旧暦12月は新暦の翌年にあたることがありますが、年の対応は変えません)。
- 他のAI補完(GitHub Copilot など)と同時に使うと、薄い文字の候補が競合して出ないことがあります。その場合の代わりとして、実際に挿入する自動機能も用意しています(下記)。
- 自動で書き換える機能は、`Ctrl+Z` で元に戻せます。

## 機能
1. **インライン補完(主な使い方)**: `天正18年` と「年」まで入力すると、カーソルの先に薄い文字で
   `（[[1590年]]）` が見えます。`Tab` キーで受け入れると入力されます(受け入れるまで文章は変わりません)。
   ウィキ記法の `[[天正]]18年` や `[[文化 (元号)|文化]]3年` にも反応します。
   併記済みの和暦、元号の範囲外の年(`天明10年`)、`[[天正18年]]` のようなリンクの中では出ません。
2. **「同〇年」「翌〇年」**: 元号を省略した `同5年`・`翌3年` の「年」の直後でも、薄い文字で西暦を提案します(Tabで確定)。
   元号は、同じ段落(空行・見出しで区切る)でそれより前にいちばん近く出てくるものを引き継ぎます。
   例: `文化2年に着任し、同5年` → `（[[1808年]]）`。「翌3年」も、直前の元号の3年として扱います(次の元号ではありません)。
   引き継ぎ元がないとき、元号の範囲を超えるときは出ません。ホバーでも、引き継いだ元号と西暦を確認できます。
   他のAI補完と競合して薄い文字が出ないことがあるため、入力が止まって約0.6秒たつと実際に挿入する方式も用意しています(既定オン。設定 `autoAnnotateRelative` で切り替え)。
   元号の `[[ ]]` 自動リンクは、この表記では動きません。
3. **元号の自動リンク**: リンクなしの元号の「年」の直後にカーソルがある状態で、入力が止まって約0.6秒たつと、元号を `[[天正]]` に書き換え、同時に西暦も挿入します
   (`天正18年` → `[[天正]]18年（[[1590年]]）`)。カーソルは文末に置かれます。西暦を入れずリンクだけにしたい場合は設定 `autoAnnotateWithLink` をオフにします(その場合、西暦は薄い文字の候補になります)。日本語入力の変換中に書き換えて入力が壊れないよう、すぐには動かしません。貼り付け、`[[天正18年` のようなリンクの途中、元号の範囲外の年では動きません。
   動かなかった分は、コマンド「リンクなしの元号を [[ ]] で囲む」で、選択範囲(なければ全文)をまとめて直せます。
   曖昧さ回避付きの記事名は、日本語版Wikipedia「元号一覧 (日本)」のリンク先で確認した8元号(文明・弘治・天文・元和・正徳・天和・安永・文化)に使い、
   たとえば `[[元和 (日本)|元和]]` になります。それ以外は `[[天正]]` です。
   設定 `warekiSeireki.eraLinkTargets` で追加・上書きもできます。
4. **ホバー表示**: 和暦にマウスを合わせると `1590年` と表示します(見るだけで、書き換えません)。
5. **重複リンクの整理**: コマンドパレットで「同じ節で重複した元号・年のリンクを外す」を実行すると、
   `== 見出し ==` ごとに、同じ元号・同じ西暦年へのリンクを**初出だけ残して**、2回目以降を文字だけにします
   (`[[天正]]4年（[[1576年]]）` → `天正4年（1576年）`)。
   **最初の概要(最初の `==` 見出しより前)は対象外**です。`=== 小見出し ===` は節を区切らず、親の節にまとめて数えます。
   見出しの行、元号・年以外のリンク、元号でない `[[文化]]`(文化の記事)は触りません。選択範囲があれば、その範囲だけに適用します
   (節の判定は全文で行います)。何度実行しても結果は同じで、`Ctrl+Z` で戻せます。
6. **併記コマンド**: コマンドパレットで「和暦の直後に西暦(年)を併記する」を実行すると、
   選択範囲(未選択なら全文)の和暦に、まとめて併記します。何度実行しても二重には併記しません。

## 差分の確認
「重複リンクの整理」は、実行すると、まず「変更前 ↔ 変更後」の差分を開きます。
右下の「適用」を押したときだけ書き換わり、「キャンセル」なら何も変わりません。確認なしで書き換えたい場合は、設定 `warekiSeireki.previewDiff` をオフにします。
(西暦の併記・元号のリンクの一括コマンドは、差分なしで、すぐに書き換えます。)

## 設定
- `warekiSeireki.previewDiff`: 重複リンクの整理を実行前に差分で確認する(既定 オン)。
- `warekiSeireki.autoLinkEra`: 元号の自動リンクのオン/オフ(既定 オン)。
- `warekiSeireki.autoAnnotateWithLink`: 元号の自動リンクと同時に西暦も挿入する(既定 オン)。
- `warekiSeireki.autoAnnotateRelative`: 「同3年」「翌3年」に西暦を実際に挿入する(既定 オン)。
- `warekiSeireki.autoLinkDelayMs`: 自動リンクまでの待ち時間(既定 600ミリ秒)。
- `warekiSeireki.eraLinkTargets`: 元号のリンク先記事名の追加・上書き。
- `warekiSeireki.inlineSuggestion`: インライン補完のオン/オフ(既定 オン)。他のAI補完機能と併用すると表示が競合することがあります。
- `warekiSeireki.linkYear`: 西暦の年にウィキリンクを付ける(既定 オン)。オン: `（[[1590年]]）` / オフ: `（1590年）`
- `warekiSeireki.parenStyle`: 括弧を全角(既定)/半角から選ぶ。

## 変換の約束事
- 対応は「その和暦年に対応する西暦年」を1つに決める慣用に従います(例: 寛政12年 = 1800年)。
  旧暦12月は新暦の翌年1〜2月にあたることがありますが、年の対応は変えません。
- 年内改元の年は2つの元号が同じ西暦年になります(慶応4年 = 明治元年 = 1868年)。
- 元号の長さを超える年(例: `天明10年`)は変換せず、ホバーと完了メッセージで知らせます。
- 元年は `元年` 表記と、数字(半角・全角)・漢数字(`十二年` など)に対応します。
- `文化財` など、元号名に似た一般語は「数字+年」が続かない限り反応しません。

## データについて
元号の元年の西暦は `eras.js` の表にあります。次の2つと照合しています。

- 日本語版Wikipedia「日本の元号一覧」の改元日(西暦)の列(応仁〜明治の52件)。47元号は開始年が一致し、
  残る文禄・正保・天保・弘化・安政の5元号は、改元日が旧暦12月で新暦の翌年1月にあたるため、
  改元日の西暦年より1年前を元年としています(立年改元。同記事の注記の安政の例を参照)。
- Node 内蔵 ICU の日本暦(各元号の内部の年 503件、不一致 0)。

出典として引用する場合は、一次資料や該当する記事で確認してください。表を直したら
`npm run verify` と `npm test` を実行します(Node.js が必要です。VS Code 本体がなくても、モックで動くテストです)。
